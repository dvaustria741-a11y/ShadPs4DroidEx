# ShadPs4DroidEx

Android port effort for [shadPS4](https://github.com/shadps4-emu/shadPS4) (PS4 emulator).

**Status: early scaffolding — does not run games yet.**

Android-only fork; there is no desktop/Windows/Linux/macOS build target here on purpose.
See [PORTING_PLAN.md](PORTING_PLAN.md) for the architecture and current blockers.
